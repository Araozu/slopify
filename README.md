# 🫧 Slopify 🫧

✨ **"The most aesthetic AI chat experience you'll ever have."** ✨

Welcome to Slopify, where we've turned "slop" into a total vibe. This is a high-performance, ultra-polished AI chat UI that makes your interactions feel like a spa day for your brain. 🧴💆‍♀️

## 💅 The Look & Feel

- **Glassmorphism everywhere:** Because your UI should be as clear as your skin after a double-cleanse. 🧊
- **SvelteKit 5 Powered:** Using the latest runes to keep things reactive and snappy. It's giving *efficiency*. ⚡️
- **Rust Backend:** A rock-solid foundation for persistence and migrations. Stronger than my morning espresso. ☕️🦀

## 🛠️ The Tech Stack (Our Skincare Routine)

| Layer | Technology | Vibe |
| :--- | :--- | :--- |
| **Frontend** | [SvelteKit 5](https://kit.svelte.dev/) | The "holy grail" framework. |
| **Styling** | [Tailwind CSS v4](https://tailwindcss.com/) | Tailored and tight. |
| **UI Components**| [shadcn-svelte](https://shadcn-svelte.com/) | Preppy and polished. |
| **Icons** | [Phosphor Icons](https://phosphoricons.com/) | Minimalist aesthetic. |
| **Backend** | [Rust](https://www.rust-lang.org/) | Deeply hydrating logic. |
| **Database** | SQLx + Migrations | Never forgets a thing. |

## 🚀 Getting Started

If you want to manifest this project locally:

### ✨ Frontend
```bash
cd frontend
vp install  # Our special ritual
vp dev      # Let the magic happen
```

### 🦀 Backend
```bash
cd backend
# Make sure you have your .env sorted!
cargo run
```
